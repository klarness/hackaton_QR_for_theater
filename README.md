# Геймифицированный WebAR-квест (Студия театрального искусства)

**MVP для хакатона «Креаторы и кодеры»**  
Команда: **WW Team (SixSeven)**

Проект представляет собой интерактивный AR-квест, который запускается прямо в мобильном браузере (без скачивания приложения). Основная задача — привлечение молодой аудитории через геймификацию с сохранением строгой айдентики театра.

На текущем этапе реализован **Frontend-макет на Vanilla JS**, включающий:
* UI/UX логику оверлея поверх камеры.
* Механизм запроса доступа к камере и вывод трансляции с задней камеры (WebRTC).
* Стейт-машину на базе `localStorage` (запоминание пройденных этапов).
* Заглушки (моки) кнопок разработчика для тестирования переходов по AR-маркерам без необходимости реального распознавания изображений.

## 🚀 Как запустить проект и протестировать на телефоне

Поскольку браузеры (iOS Safari, Android Chrome) требуют обязательного **HTTPS**-соединения для доступа к камере телефона, запуск состоит из двух этапов: запуска локального сервера и проброса туннеля (чтобы получить https-ссылку).

Вам потребуется установленный [Node.js](https://nodejs.org/).

### Шаг 1. Запуск локального сервера
Откройте первый терминал (командную строку) в папке с проектом и выполните команду:
```bash
npx serve -p 3000
```
*Локальный сервер запустится и начнет отдавать файлы на порту 3000. Оставьте это окно открытым.*

### Шаг 2. Создание защищенного туннеля (HTTPS)
Чтобы с телефона зайти на ваш компьютер, откройте **второй терминал** и запустите бесплатный туннель (через встроенный в Windows SSH-клиент).

Рекомендуемый способ (работает стабильнее всего, без блокировок):
```bash
ssh -R 80:localhost:3000 nokey@localhost.run -o StrictHostKeyChecking=no
```
В терминале выведется строка с вашим публичным адресом, например:
`ca5aa7ca03b42f.lhr.life tunneled with tls termination, https://ca5aa7ca03b42f.lhr.life`

*(Альтернатива, если localhost.run недоступен — можно использовать LocalTunnel)*:
```bash
npx localtunnel --port 3000
```

### Шаг 3. Тестирование с телефона
1. Откройте полученную **https://** ссылку в браузере телефона.
2. Нажмите **«Разрешить доступ и начать»** на стартовом экране.
3. Разрешите браузеру доступ к камере.
4. Используйте появившиеся кнопки **[Dev] Скан marker1** и **[Dev] Скан marker2** для имитации сканирования физических QR-кодов.
5. Пройдите диалог до конца, чтобы получить промокод на скидку и протестировать редирект на сайт `sti.ru`.

## 🛠 Стек технологий MVP
* **HTML5 / CSS3 / Vanilla JS** — чистый фронтенд ради 100% стабильности работы на улице при плохом интернете.
* **WebRTC API (`navigator.mediaDevices`)** — для доступа к камере смартфона.
* **localStorage** — для сохранения прогресса игрока между закрытиями браузера.

В будущем в проект планируется интеграция `A-Frame` и `MindAR` для реального рендеринга 3D-моделей (.glb) поверх отсканированных маркеров.
